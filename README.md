# C# ADSO

Repositorio de prácticas de C# del programa Análisis y Desarrollo de Software (ADSO) del SENA.

## Comparación de instrucciones: Python, JavaScript y C#

| Instrucción | Python | JavaScript | C# |
|---|---|---|---|
| Mostrar texto | `print("Hola")` | `console.log("Hola");` | `Console.WriteLine("Hola");` |
| Leer datos | `input("Nombre: ")` | `prompt("Nombre:");` | `Console.ReadLine();` |
| Crear una variable | `nombre = "Ana"` | `let nombre = "Ana";` | `string nombre = "Ana";` |
| Condicional | `if edad >= 18:` | `if (edad >= 18) { }` | `if (edad >= 18) { }` |
| Ciclo | `for i in range(3):` | `for (let i = 0; i < 3; i++) { }` | `for (int i = 0; i < 3; i++) { }` |
| Crear una función | `def saludar():` | `function saludar() { }` | `void Saludar() { }` |
